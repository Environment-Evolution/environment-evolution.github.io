01 / OVERVIEW

Diverse workflows.
Executable terminal tasks.

Scenarios connect skills.
Paths become tasks.

SkillSynth is a terminal task synthesis framework from the Hunyuan Team at Tencent (Tencent Hy). It samples workflows from a scenario-mediated skill graph and uses a multi-agent harness to build, verify, and repair diverse executable tasks for training terminal agents.

In the skill graph, scenarios form the nodes and real terminal skills connect them as directed transitions. Sampling paths from this graph yields coherent workflows with diverse scenario–skill combinations.

A multi-agent harness turns each workflow into an executable task, then verifies and repairs it. The resulting tasks support trajectory collection for training terminal agents.

02 / METHOD

Build the graph.
Sample paths. Synthesize tasks.

A directed path specifies which skills to apply and the intermediate scenarios they traverse.

01

Construct the skill graph

Collect terminal skills, infer preconditions and postconditions, and align compatible scenarios to connect skills into a graph.

02

Sample diverse workflows

Favor less-visited scenarios and less-used skills. Retain unique paths of one to seven skills without revisiting a scenario or skill within a path.

03

Synthesize and verify

A planner designs the task; a constructor implements it. Execution and rubric checks return feedback for iterative repair.

EXECUTION-BASED VERIFICATION

Check solvability

Run the oracle solution and verification scripts inside the task container. A successful execution confirms that the task can be solved.

RUBRIC-BASED VERIFICATION

Check task quality

Check instruction–test alignment and instruction self-containedness. Failed checks return diagnostic feedback to the constructor for repair.

The harness permits up to three repair cycles, with at most 20 tool calls per cycle. Interactive repair recovers 721 task instances that failed in the first round.

05 / PAPER

Abstract

Terminal agents have demonstrated strong potential for autonomous command-line execution, yet their training remains constrained by the scarcity of high-quality and diverse execution trajectories. Existing approaches mitigate this bottleneck by synthesizing large-scale terminal task instances for trajectory sampling. However, they primarily focus on scaling the number of tasks while providing limited control over the diversity of execution trajectories that agents actually experience during training.

In this paper, we present SkillSynth, an automated framework for terminal task synthesis built on a scenario-mediated skill graph. SkillSynth first constructs a large-scale skill graph, where scenarios serve as intermediate transition nodes that connect diverse command-line skills. It then samples paths from this graph as abstractions of real-world workflows, and uses a multi-agent harness to instantiate them into executable task instances. By grounding task synthesis in graph-sampled workflow paths, SkillSynth explicitly controls the diversity of minimal execution trajectories required to solve the synthesized tasks. Experiments on Terminal-Bench demonstrate the effectiveness of SkillSynth. Moreover, task instances synthesized by SkillSynth have been adopted to train Hy3 Preview, contributing to its enhanced agentic capabilities in terminal-based settings.

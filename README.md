# Environment Evolution

Project page for [Environment Evolution for Terminal Agents](https://arxiv.org/abs/2609.04128).

Static HTML, CSS, and JavaScript. GitHub Pages publishes `main` from the repository root.

Preview locally with `python3 -m http.server 8766`.

Paper text, author order, results, and the seven original SVG figures follow arXiv:2609.04128v1. Paper and figures are attributed to Fan et al. (2026), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The Tencent Hy logo is the official asset supplied for this project and is not covered by the paper's license.
